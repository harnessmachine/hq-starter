# Штаб · стартовая папка

Штаб — точка входа для всех проектов и агентов. Здесь правила, паспорт владельца, карта отделов и задачи. Работа живёт в отделах, отдельных папках рядом со штабом.

```text
~/Work/
├── HQ/                      ← штаб, агента открываешь всегда здесь
│   ├── ME.md                ← кто я
│   ├── MAP.md               ← какие у меня отделы
│   ├── TASKS.md             ← доска задач
│   └── tasks/
│       └── site-prototype/  ← одна задача = одна папка
│           └── task.md      ← зачем, критерии, журнал
│
├── BIZ_Modular_Houses/      ← отдел: здесь лежит сама работа
└── DEP_Research/            ← отдел
```

## Как работать

```text
 «запиши во Входящие …»          → строка в TASKS.md
          │
 «заведи задачу …»               → tasks/<slug>/task.md
          │
 /grill-with-docs                → агент допрашивает, пока не станет ясно
 /to-spec  →  /to-tickets        → план и этапы в папке задачи
          │
     работа в отделе             → результат лежит в BIZ_… / DEP_…
          │
 «на сегодня всё»                → агент сам пишет журнал задачи
          │
 новый чат: «продолжаем задачу …» → агент знает, где остановились
```

Задачами занимается скилл `manager`. Его не нужно вызывать: агент запускает его сам, когда речь о задачах и когда ты заканчиваешь. Если итог не записался, скажи «запиши итог».

Статусы задач — три: `в работе`, `ждёт меня`, `готово`. `готово` ставишь только ты.

## Как начать

1. Распаковать папку в путь без кириллицы и пробелов, например `~/Work/HQ`.
2. Открыть в ней агента: Claude Code или Codex.
3. Спросить: «Расскажи, что в этой папке».
4. Паспорт `ME.md`:
   ```text
   /grill-with-docs
   Цель: хочу в ME.md собрать контекст обо мне: кто я, роль, бизнес и текущие проекты, как я принимаю решения, как со мной говорить и чего не делать, какими агентами и сервисами пользуюсь. ME.md до 60 строк, запиши только после моего подтверждения.
   ```
5. Проверка: новый чат, вопрос «Что ты знаешь обо мне?».
6. Задачи из головы сырьём: «Запиши во Входящие: …».
7. Первая задача: «Заведи задачу: …». Агент спросит цель, отдел и критерии приёмки.
8. Первый отдел — только под конкретную задачу: `/new-otdel`.

В Codex скиллы вызываются словами: «Запусти скилл grill-with-docs».

## Что внутри

| Путь | Зачем |
| --- | --- |
| `ME.md`, `MAP.md`, `TASKS.md` | Паспорт, карта отделов, доска задач. Твои файлы |
| `tasks/` | Папки задач |
| `AGENTS.md` | Устав штаба для агента. `CLAUDE.md` — ссылка на него, Claude и Codex читают одно и то же |
| `_archive/` | Сюда убирается старое, ничего не удаляя |
| `_system/` | Служебное для агента: настройки, шаблоны, словарь и решения. Открывать не нужно |
| `.agents/skills/` | Скиллы. `.claude/skills` смотрит туда же |

Скиллы, которые вызываешь ты: `grill-with-docs`, `to-spec`, `to-tickets`, `new-otdel`. Сам агент вызывает `manager`. Служебные: `grilling` и `domain-modeling`.

| Скилл | Откуда |
| --- | --- |
| `grill-with-docs`, `grilling`, `domain-modeling`, `to-spec`, `to-tickets` | Мэтт Покок, [mattpocock/skills](https://github.com/mattpocock/skills), MIT, без изменений. Настроены на локальные задачи через `_system/agents/`, `setup-matt-pocock-skills` запускать не нужно |
| `manager`, `new-otdel` | Авторские |

## Три правила, которые держат порядок

- Агент стартует только из штаба.
- Работа идёт по задаче, каждая сессия оставляет запись в её журнале.
- Новый отдел появляется только под конкретную задачу.
