# Штаб · стартовая папка

Штаб — точка входа для всех проектов и агентов. Работы здесь нет: только правила, паспорт владельца, карта отделов и задачи. Каждое направление живёт в своём отделе, отдельной папке рядом со штабом.

```text
~/Work/
├── HQ/                   ← эта папка, агент открывается здесь
├── BIZ_Modular_Houses/   ← отдел: направление бизнеса
└── DEP_Research/         ← отдел: повторяемый метод
```

## Как начать

1. Распаковать папку в путь без кириллицы и пробелов, например `~/Work/HQ`.
2. Открыть в ней агента: Claude Code или Codex.
3. Спросить: «Расскажи, что в этой папке». Агент должен назвать `AGENTS.md`, `ME.md`, `MAP.md`, `TASKS.md` и скиллы.
4. Контекст о владельце в `ME.md` через `grill-me`:
   ```text
   /grill-me
   Цель: хочу в ME.md собрать контекст обо мне: кто я, роль, бизнес и текущие проекты, как я принимаю решения, как со мной говорить и чего не делать, какими агентами и сервисами пользуюсь. ME.md до 60 строк, запиши только после моего подтверждения.
   ```
5. Проверка: новый чат, вопрос «Что ты знаешь обо мне?». В ответе есть то, что владелец вписал сам.
6. Первый отдел — только под конкретную задачу:
   ```text
   /new-otdel
   Задача: вывести модульные дома на открытый рынок.
   ```
7. В конце работы: `/handoff`. Агент сохранит документ передачи во временную папку и назовёт путь. Новая сессия начинает с него.

В Codex скиллы вызываются словами: «Запусти скилл grill-me».

## Что внутри

| Файл | Зачем |
| --- | --- |
| `AGENTS.md` | Устав штаба: как агент работает. `CLAUDE.md` — ссылка на него, Claude и Codex читают одно и то же |
| `ME.md` | Паспорт владельца |
| `MAP.md` | Карта отделов |
| `TASKS.md` | Задачи сегодня и на неделе |
| `_templates/otdel/` | Заготовка отдела |
| `_archive/` | Сюда убирается старое, ничего не удаляя |
| `.agents/skills/` | Скиллы `grill-me` и `handoff` (оригиналы Мэтта Покока, mattpocock/skills, MIT — лицензия лежит рядом), `new-otdel` (авторский). `.claude/skills` смотрит туда же |

## Три правила, которые держат порядок

- Агент стартует только из штаба.
- Каждый факт записан в одном месте, остальные ссылаются.
- Новый отдел появляется только под конкретную задачу.
