# Штаб · стартовая папка

Штаб — точка входа для всех проектов и агентов. Здесь правила, паспорт владельца, карта отделов и задачи. Работа живёт в отделах, отдельных папках рядом со штабом.

```text
~/Work/
├── HQ/                   ← эта папка, агент открывается здесь
│   └── tasks/            ← задачи: тикет, спека, фазы, передачи смены
├── BIZ_Modular_Houses/   ← отдел: направление бизнеса
└── DEP_Research/         ← отдел: повторяемый метод
```

## Как начать

1. Распаковать папку в путь без кириллицы и пробелов, например `~/Work/HQ`.
2. Открыть в ней агента: Claude Code или Codex.
3. Спросить: «Расскажи, что в этой папке». Агент должен назвать `AGENTS.md`, `ME.md`, `MAP.md`, `TASKS.md`, папку `tasks/` и скиллы.
4. Контекст о владельце в `ME.md` через `grill-me`:
   ```text
   /grill-me
   Цель: хочу в ME.md собрать контекст обо мне: кто я, роль, бизнес и текущие проекты, как я принимаю решения, как со мной говорить и чего не делать, какими агентами и сервисами пользуюсь. ME.md до 60 строк, запиши только после моего подтверждения.
   ```
5. Проверка: новый чат, вопрос «Что ты знаешь обо мне?». В ответе есть то, что владелец вписал сам.
6. Задачи из головы сырьём: «Запиши во Входящие: …».
7. Первая задача в работу. Скилл `manager` подхватит сам:
   ```text
   Заведи задачу: собрать отзывы о модульных домах и разложить по болям.
   ```
8. Первый отдел — только под конкретную задачу:
   ```text
   /new-otdel
   Задача: tasks/<slug>/task.md
   ```
9. Большую задачу сначала грилим, потом пишем спеку и режем на фазы. Всё пишется в папку задачи:
   ```text
   /grill-with-docs   ← допрос по задаче, решения в docs/adr/
   /to-spec           ← tasks/<slug>/spec.md
   /to-tickets        ← tasks/<slug>/issues/01-…md
   ```
10. В конце работы `manager` сам пишет итог сессии в журнал задачи, для большой работы ещё и передачу в `tasks/<slug>/handoff/`. Если не записал, скажи «запиши итог». Новая сессия: «Продолжаем задачу <slug>».
11. В любой момент: «Что у нас по задачам?»

В Codex скиллы вызываются словами: «Запусти скилл grill-with-docs».

## Что внутри

| Путь | Зачем |
| --- | --- |
| `AGENTS.md` | Устав штаба: как агент работает и как живёт задача. `CLAUDE.md` — ссылка на него, Claude и Codex читают одно и то же |
| `ME.md` | Паспорт владельца |
| `MAP.md` | Карта отделов |
| `TASKS.md` | Доска задач: входящие, задачи со статусом, готово |
| `tasks/` | Папки задач |
| `docs/agents/` | Как скиллы ведут задачи и словарь. Отдельно настраивать ничего не нужно |
| `_templates/` | Заготовки отдела и тикета |
| `_archive/` | Сюда убирается старое, ничего не удаляя |
| `.agents/skills/` | Скиллы. `.claude/skills` смотрит туда же |

Скиллы:

| Скилл | Откуда |
| --- | --- |
| `grill-me`, `grilling`, `grill-with-docs`, `domain-modeling`, `to-spec`, `to-tickets` | Мэтт Покок, [mattpocock/skills](https://github.com/mattpocock/skills), MIT, без изменений |
| `manager`, `new-otdel` | Авторские. `manager` — единственный, кто ведёт задачи, и сам закрывает сессию записью в журнал |

`setup-matt-pocock-skills` запускать не нужно: настройка уже лежит в `docs/agents/` и в конце `AGENTS.md`.

## Три правила, которые держат порядок

- Агент стартует только из штаба.
- Работа идёт по задаче, каждая сессия оставляет запись в её журнале.
- Новый отдел появляется только под конкретную задачу.
