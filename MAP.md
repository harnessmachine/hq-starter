# Карта отделов

> Один отдел — одна папка рядом со штабом (позже — свой репозиторий). Путь пишется относительно штаба: `../<ИМЯ>`. Префиксы: `BIZ_` — направления бизнеса, `DEP_` — повторяемые методы, которые обслуживают разные направления (исследования, парсинг). Новый отдел добавляет скилл `new-otdel` и только под конкретную задачу.
